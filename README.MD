# 💬 Pulse-Chat — Real-Time Messaging App

A full-stack real-time chat application built with the **MERN stack** (MongoDB, Express.js, React, Node.js) and **Socket.IO** for instant messaging.

---

## ✨ Key Features

* **User Authentication:** JWT and bcryptjs-powered signup, login, and password encryption.
* **Real-Time Messaging:** Instant delivery and live typing indicators via Socket.IO.
* **One-on-One & Group Chats:** Direct messages and customizable group channels.
* **Cloud Media Uploads:** Profile picture management via Cloudinary.
* **Responsive Interface:** Clean UI built with React.

---

## 🚀 Getting Started

1. **Clone the Repository:**
   ```bash
   git clone https://github.com[Your-GitHub-Username]/[Your-Repo-Name].git
   cd [Your-Repo-Name]
   ```
2. **Install Dependencies:**
   ```bash
   npm install
   cd frontend && npm install && cd ..
   ```
3. **Configure Environment Variables:** Create a `.env` file in the backend with your MongoDB URI, JWT secrets, and Cloudinary credentials.
4. **Run the Application:**
   * Start backend: `npm start`
   * Start frontend: `cd frontend && npm start`
